= 使用非主要管理節點取代 StorageGRID 主要管理節點
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
若要恢復主管理節點、您必須先更換實體或虛擬硬體。

* 您可以將發生故障的主要管理節點替換為在同一平台上執行的主要管理節點。
* 您可以將執行在 VMware 或 Linux 主機上的主要管理節點取代為託管在 StorageGRID 服務應用裝置上的主要管理節點。
* 您可以將執行在 VMware 主機上的主要管理節點替換為 SG1000 或 SG100 服務應用裝置。


請使用符合您為節點所選替換平台的程序。完成節點更換程序（適用於所有節點類型）之後、該程序將引導您進行主要管理節點恢復的下一步。
