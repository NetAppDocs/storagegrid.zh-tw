= 選擇 Start Recovery 以配置 StorageGRID 應用裝置儲存節點
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您必須在Grid Manager中選取「Start Recovery」（開始還原）、才能將應用裝置儲存節點設定為故障節點的替換節點。

.開始之前
* 您已使用登入 Grid Manager link:../admin/web-browser-requirements.html["支援的網頁瀏覽器"]。
* 您有link:../admin/admin-group-permissions.html["維護或根存取權限"]。
* 您有資源配置通關密碼。
* 您已部署恢復設備儲存節點。
* 您擁有任何修復工作的開始日期、可用於銷毀編碼資料。


.步驟
. 從 Grid Manager 中，選擇 *Maintenance* > *Tasks* > *Node recovery*。
. 在「Pending Node」（擱置節點）清單中選取您要恢復的網格節點。
+
節點在故障後會出現在清單中、但您無法選取節點、直到節點重新安裝並準備好恢復為止。

. 請輸入*佈建密碼*。
. 選擇 *Start recovery*。
+
image:4b_select_recovery_node.png["螢幕截圖顯示「維護 > 恢復」頁面"]

. 監控恢復網格節點表格中的恢復進度。
+
** 如果網格節點達到「等待手動步驟」階段，您必須link:../maintain/remounting-and-reformatting-appliance-storage-volumes.html["手動重新掛載並重新格式化應用裝置儲存設備磁碟區"]。
** 如果未出現「等待手動步驟」訊息，則表示儲存設備磁碟區已自動重新掛載和重新格式化，您可以link:../maintain/restoring-object-data-to-storage-volume-for-appliance.html["將物件資料還原到磁碟區中"]。




[NOTE]
====
在恢復過程中的任何階段，您都可以選擇 *Reset* 來開始新的恢復。此時會出現一個對話方塊，提示如果您重設程序，節點將處於不確定狀態。

如果您想在重設程序後重試恢復、則必須在節點上執行、將應用裝置節點還原為預先安裝的狀態 `sgareinstall`。
