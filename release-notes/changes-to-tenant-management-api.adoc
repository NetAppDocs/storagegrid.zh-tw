= StorageGRID 中租戶管理 API 的變更
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 12.1 使用租戶管理 API 的第 4 版。第 4 版已棄用第 3 版；但是，第 1 版、第 2 版和第 3 版仍受支援。


NOTE: 您可以繼續在 StorageGRID 中使用已棄用的租戶管理 API 版本；但是，StorageGRID 的未來版本將不再支援這些 API 版本。升級至 StorageGRID 12.0 或更新版本後，您可以使用 `PUT /grid/config/management` API 停用已棄用的 API。

若要深入瞭解link:../tenant/understanding-tenant-management-api.html["瞭解租戶管理API"]、請前往。



[[new-api-for-object-replication]]
== 用於物件複製的新 API

您可以使用 `/org/cross-grid-replication/{versionId}/replicate`用於在新配置了跨網格複製的現有儲存桶上手動複製物件的 API。
