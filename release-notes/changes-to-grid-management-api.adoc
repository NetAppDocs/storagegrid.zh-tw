= StorageGRID 中 Grid Management API 的變更
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 12.1 使用 Grid Management API 的第 4 版。第 4 版已棄用第 3 版；但是，第 1 版、第 2 版和第 3 版仍受支援。


NOTE: 您可以繼續使用已棄用的 StorageGRID 管理 API 版本；但是，StorageGRID 的未來版本將不再支援這些 API 版本。升級至 StorageGRID 12.0 或更新版本後，您可以使用 `PUT /grid/config/management` API 停用已棄用的 API。

若要深入瞭解link:../admin/using-grid-management-api.html["使用Grid Management API"]、請前往。



[[new-endpoints-for-changing-the-bmc-password-and-lan-ip-settings]]
== 用於變更 BMC 密碼和 LAN IP 設定的新端點

已新增以下端點，以便您可以link:../harden/hardening-guidelines-for-storagegrid-nodes.html#change-appliance-bmc-password["更改應用裝置 BMC 密碼"]。

`PUT /bmc-configuration/root-password`

已新增以下端點，以便您可以link:../maintain/changing-nodes-network-configuration.html#change-appliance-node-bmc-lan-ip-settings["更改或檢視 BMC LAN IP 設定"]。

`PUT /grid/bmc/{node-id}/lan-ip-config`

`GET /grid/bmc/{node-id}/lan-ip-config`
